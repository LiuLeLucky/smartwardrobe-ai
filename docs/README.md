# SmartWardrobe-AI

## AI 智能衣柜助手功能结构图（文字版）

1. 用户衣柜模块
	•	衣服录入：拍照 + AI 识别（类型、颜色、图案、面料）
	•	衣柜数据库：存储衣物信息 + 使用记录
	•	历史穿搭记录：每天穿搭、穿搭频率统计

2. 场景与风格输入
	•	用户输入场景：约会、工作、旅行、聚会等
	•	用户选择/设定风格：日系甜美、Miu Miu、Ralph Lauren、欧美简约等
	•	可选限制条件：季节、天气、颜色偏好

3. AI 搭配生成
	•	搭配生成引擎：
	•	根据衣柜信息 + 场景 + 风格生成多套搭配
	•	可跨季节/气候调整搭配
	•	搭配评分系统：
	•	A：完美匹配（衣柜齐全 + 风格协调 + 色彩和谐）
	•	B：一般匹配（缺少部分关键单品，可改进）
	•	C：勉强匹配（搭配勉强可行，需要补充单品）

4. 搭配改进与建议
	•	对 B/C 等级搭配，AI 提供提升方案：
	•	“添加一件中性色外套”
	•	“换一双小红鞋”
	•	“缺少裙子类型，可考虑补充类似款”
	•	建议基于 衣柜现有单品 + 学习的搭配规则

5. AI 风格学习模块
	•	数据来源：小红书、Pinterest、公开品牌搭配（Miu Miu、Chanel、Urban Outfitters、Zara、优衣库等）
	•	学习内容：
	•	色彩搭配规则
	•	风格元素（品牌/风格特点）
	•	层次感与混搭规则
	•	AI 不断优化搭配生成和评分算法

6. 输出
	•	用户每日搭配推荐（多套可选）
	•	搭配评分及改进建议
	•	穿搭数据可视化：频率高的单品、低频单品提醒

## 快速开始
1. 安装依赖: `pip install -r requirements.txt`
2. 配置文件: `.env` (需配置 API_KEY)
3. 启动后端: `uvicorn app.main:app --reload`
4. 启动演示前端: `streamlit run app/ui.py` (开发中)
