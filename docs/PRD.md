# AI 智能衣柜助手 - 产品需求文档 (PRD)

## 1. 项目目标
打造一个结合 CV 与 LLM 的个人穿搭助手，解决“不知道穿什么”和“衣服利用率低”的痛点。

## 2. 核心功能模块
### M1: 用户衣柜模块
- **录入**：支持拍照上传，通过 AI 识别类型、颜色、图案、面料。
- **数据库**：持久化存储衣物属性及穿搭历史。
- **统计**：统计单品穿搭频率。

### M2: 场景与风格输入
- **场景**：约会、工作、旅行、聚会等。
- **风格**：日系甜美、Miu Miu、Ralph Lauren、欧美简约等。
- **限制**：季节、天气、个人颜色偏好。

### M3: AI 搭配生成与评分
- **引擎**：基于衣柜数据 + 场景 + 风格生成多套方案。
- **评分系统**：
  - A：完美（匹配场景+风格协调）。
  - B：一般（缺少关键件，可改进）。
  - C：勉强（需补充单品）。

### M4: 搭配改进建议
- 针对 B/C 级给出具体提升建议（如“建议加一件中性外套”）。

### M5: User Table
- id: 用户ID
- email： 用户邮箱
- created_at： 创建时间

### M6: 风格学习模块 (后期)
- 抓取流行趋势，优化搭配算法。

## 3. 预留扩展节点
- `image_feature_vector`: 为后期 CV 特征匹配预留。
- `style_rules_id`: 为后期风格学习库预留关联 ID。
